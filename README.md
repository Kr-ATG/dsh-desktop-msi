# DeepSeek Harness 桌面安装包（Windows）

本仓库只用于发布 **DeepSeek Harness 桌面版（DSH）的 Windows 安装包（MSI）**，不包含任何源码。

## 下载

前往 [Releases](https://github.com/Kr-ATG/dsh-desktop-msi/releases) 下载最新版。

- **最新版本：v1.1.33**
- 安装包文件名：`DeepSeek-Harness-1.1.33.msi`

直链示例：

```text
https://github.com/Kr-ATG/dsh-desktop-msi/releases/download/v1.1.33/DeepSeek-Harness-1.1.33.msi
```

## 安装步骤

1. 下载 `DeepSeek-Harness-1.1.33.msi` 后双击安装。
2. 若被 Windows SmartScreen 拦截，点击「更多信息」→「仍要运行」。
3. 建议使用默认安装路径，方便后续版本原地更新。

## 版本规则

Tag 与安装包内版本号保持一致，形如 `v1.1.33`。全部历史版本见 [Releases](https://github.com/Kr-ATG/dsh-desktop-msi/releases)。
